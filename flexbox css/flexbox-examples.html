6. order

Visually reorders items without changing the HTML.

1 (order:3)
2 (order:1)
3 (order:2)
.item-1 { order: 3; }
.item-2 { order: 1; }
.item-3 { order: 2; }
/* default order is 0; lower numbers come first */

7. flex-grow, flex-shrink, flex-basis (shorthand: flex)

flex-grow — how items share extra space

grow:1
grow:2
grow:1

flex-basis + flex:1 — fixed sidebar + fluid content

fixed 200px
flex: 1 (fills rest)
/* shorthand: flex: grow shrink basis; */
.sidebar { flex: 0 0 200px; }  /* don't grow, don't shrink, 200px wide */
.content { flex: 1; }          /* grow to fill remaining space */

.item-a { flex-grow: 1; }
.item-b { flex-grow: 2; } /* takes twice as much extra space as item-a */

Cheat Sheet Summary

/* CONTAINER properties */
display: flex;
flex-direction: row | row-reverse | column | column-reverse;
flex-wrap: nowrap | wrap | wrap-reverse;
justify-content: flex-start | flex-end | center | space-between | space-around | space-evenly;
align-items: stretch | flex-start | flex-end | center | baseline;
align-content: flex-start | flex-end | center | space-between | space-around | stretch;
gap: 10px; /* row-gap column-gap */

/* ITEM properties */
order: 0;               /* default 0, lower = earlier */
flex-grow: 0;            /* default 0, how much to grow */
flex-shrink: 1;          /* default 1, how much to shrink */
flex-basis: auto;        /* starting size before grow/shrink */
flex: 0 1 auto;          /* shorthand for grow shrink basis */
align-self: auto | flex-start | flex-end | center | baseline | stretch;
